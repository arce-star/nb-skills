# Security policy

nbskills analyzes third-party Agent Skills and may fetch public repository content. Treat remote skills as untrusted input.

## Reporting a vulnerability

Please open a GitHub security advisory rather than a public issue when a vulnerability would enable command execution, credential exposure, path traversal, or unsafe installation behavior.

## Scope

The built-in audit is a heuristic static scanner. A clean result is not a guarantee that a third-party skill is safe.
